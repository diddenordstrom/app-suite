# The repo is public

app-suite is public on GitHub (see [docs/decisions/open-source.md](../../docs/decisions/open-source.md)). Everything committed, including `docs/`, test fixtures, demo data and commit messages, can be read by anyone.

- Keep sensitive and personal information out: health details (injuries, pain, medical history), names of the owner, friends or colleagues, email addresses, home or other real locations, personal races and results, and links to private chats or canvases.
- Write about the owner's needs in general terms: "a runner with a sensitive knee", not "the owner's right knee hurts". Rules for an app are fine; notes about a person are not.
- When a chat contains personal details, leave them in the chat. If a decision depends on them, write down the decision and the general reason only.
